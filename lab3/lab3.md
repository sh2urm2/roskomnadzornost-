# Лабораторна робота №3

**Тема:** Робота з умовами в розмітці. Застосування конструкцій `if-else` для зміни візуального оформлення елементів сторінки.

## Фрагмент коду

Логічна змінна та альтернативний синтаксис `if-else` для виведення статусу завдання:

```php
<?php
$taskName = "Верстка головної сторінки";
$isCompleted = true;
?>

<li class="<?= $isCompleted ? 'task-done' : 'task-pending' ?>">
    <?= $taskName ?> —
    <?php if ($isCompleted == true): ?>
        ✔️ Виконано
    <?php else: ?>
        🕒 В процесі
    <?php endif; ?>
</li>
```

CSS-класи для візуальної відмінності стану завдання:

```css
.task-done {
    color: green;
    text-decoration: line-through;
}
.task-pending {
    color: gray;
}
```

Тернарний оператор у атрибуті `class` динамічно обирає CSS-клас залежно від значення `$isCompleted` без використання громіздкого `if-else`.

## Контрольні запитання

**1. Які оператори порівняння існують у PHP (назвіть мінімум 4)?**

У PHP є такі оператори порівняння: `==` (рівність значень), `===` (тотожність — значення і тип), `!=` або `<>` (нерівність), `!==` (нетотожність), `<`, `>`, `<=`, `>=` (менше/більше, з рівністю чи без), а також `<=>` (spaceship-оператор, що повертає -1, 0 або 1).

**2. У чому різниця між `===` та `==` у PHP? Приклад.**

Оператор `==` перед порівнянням приводить операнди до спільного типу (type juggling), тоді як `===` порівнює і значення, і тип без будь-якого приведення. Через це результати можуть відрізнятись:

```php
var_dump(0 == "abc");   // false у PHP 8+ (у PHP 7 було true)
var_dump("1" == "01");  // true — обидва рядки приводяться до чисел
var_dump("1" === "01"); // false — рядки різні, попри однакове числове значення
var_dump(0 === "0");    // false — різні типи (int і string)
```

Тому в PHP рекомендують за замовчуванням використовувати `===`, щоб уникнути неочевидних неявних перетворень типів.

**3. Для чого потрібен альтернативний синтаксис `if (...): ... endif;` під час роботи з HTML?**

Коли PHP-код чергується з великими блоками HTML-розмітки, використання фігурних дужок `{ }` створює багато відкритих і закритих `<?php ?>` вставок, які важко зіставляти одна з одною — код перетворюється на "спагеті". Альтернативний синтаксис (`if (...):`, `else:`, `endif;`, аналогічно для `foreach`, `while`, `for`) робить межі умовного блоку явними прямо в розмітці й значно покращує читабельність шаблонів, у яких логіка перемежовується з HTML-тегами.

**4. Що таке тернарний оператор і який синтаксис? Коли він недоцільний?**

Тернарний оператор — скорочена форма `if-else`, що повертає одне з двох значень залежно від умови. Синтаксис:

```php
$result = умова ? значення_якщо_true : значення_якщо_false;
```

Існує й скорочена форма `$a ?: $b`, яка повертає `$a`, якщо воно truthy, інакше — `$b`.

Використання тернарного оператора недоцільне, коли:
- умова складна або потрібно перевірити кілька умов одночасно (вкладені тернарники різко знижують читабельність);
- у кожній гілці потрібно виконати не одне значення, а послідовність дій;
- пріоритет — зрозумілість коду, а не його стислість.

**5. Які значення в PHP приводяться до `false` в умові `if` (type juggling)?**

До `false` приводяться:
- саме значення `false`;
- числа `0` та `0.0`;
- рядок `"0"`;
- порожній рядок `""`;
- `null`;
- порожній масив `[]`;
- об'єкт `SimpleXMLElement`, створений з порожніх XML-тегів (особливий випадок).

Усі інші значення (включно з рядками `"0.0"`, `" "`, `"false"`) вважаються `true`.
