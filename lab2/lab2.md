# Лабораторна робота №2

**Тема:** Виведення динамічного контенту. Створення базової HTML-структури сайту та інтеграція PHP-змінних одразу у розмітку.

## Фрагмент коду

Оголошення змінних (на початку `index.php`, до `<!DOCTYPE html>`):

```php
<?php
$appName = "Task Manager";
$taskTitle = "Вивчити основи PHP";
$taskTimeEstimate = 3;
?>
```

Виклик змінних у розмітці (всередині `<body>`):

```php
<header>
    <h1><?= $appName ?></h1>
</header>
<main>
    <ul>
        <li>Завдання: <?= $taskTitle ?></li>
        <li>Оцінка часу: <?= $taskTimeEstimate ?> год.</li>
    </ul>
</main>
```

## Контрольні запитання

**1. Що таке динамічна типізація і як вона працює в PHP?**

Динамічна типізація означає, що тип змінної визначається автоматично під час виконання програми, залежно від значення, яке їй присвоєно, а не оголошується заздалегідь. Одна й та сама змінна може змінювати тип протягом виконання скрипта:

```php
$var = 10;        // int
$var = "текст";   // string
$var = 3.14;      // float
```

PHP сам конвертує типи при необхідності (неявне приведення типів), наприклад при порівнянні чи арифметичних операціях.

**2. Як правильно розпочати і закрити блок з PHP-кодом всередині HTML-документа?**

```php
<?php
    // код PHP
?>
```

Все, що знаходиться між `<?php` та `?>`, інтерпретується як PHP-код, решта документа сприймається як звичайний HTML і передається у вивід без змін. Закриваючий тег `?>` можна опускати, якщо файл містить лише PHP-код (рекомендується для файлів без HTML, щоб уникнути помилок з зайвими пробілами/переносами рядків після тега).

**3. В чому різниця між записами `<?php echo $var; ?>` та `<?= $var ?>`?**

`<?= $var ?>` — це скорочена (short echo) форма запису, еквівалентна `<?php echo $var; ?>`. Функціонально вони ідентичні — виводять значення змінної. Відмінність лише синтаксична: коротка форма зручніша при частому виведенні змінних у HTML-розмітці (наприклад, у шаблонах) і завжди доступна в PHP, починаючи з версії 5.4, незалежно від налаштування `short_open_tag`.

**4. Які основні (скалярні) типи даних підтримує PHP? Наведіть приклади.**

| Тип | Опис | Приклад |
|---|---|---|
| `int` (integer) | ціле число | `$a = 25;` |
| `float` (double) | число з плаваючою комою | `$b = 3.14;` |
| `string` | рядок символів | `$c = "Привіт";` |
| `bool` (boolean) | логічне значення | `$d = true;` |

(Складені типи — `array`, `object`; спеціальні — `null`, `resource` — до скалярних не належать.)

**5. Що буде виведено в браузері, якщо користувач відкриє файл `.html`, всередині якого буде вбудовано `<?php echo "Test"; ?>` без налаштувань сервера? Поясніть чому.**

Браузер виведе буквально:

```
<?php echo "Test"; ?>
```

Файли з розширенням `.html` обробляються веб-сервером як статичний HTML і не передаються інтерпретатору PHP. Сервер визначає, який обробник застосувати, саме за розширенням файлу (зазвичай це `.php`). Оскільки код PHP не виконується, він потрапляє у вихідний HTML як звичайний текст, і браузер відображає його "як є", оскільки для нього це просто текст усередині документа.
