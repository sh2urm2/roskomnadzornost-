# Лабораторна робота №4

**Тема:** Форматування даних власними функціями.

## Код функцій

```php
function formatTitle($text, $maxLength = 20) {
    if (strlen($text) > $maxLength) {
        return substr($text, 0, $maxLength) . "...";
    }
    return $text;
}

function getCurrentGreeting() {
    $hour = (int) date('H');

    if ($hour >= 6 && $hour <= 11) {
        return "Доброго ранку";
    } elseif ($hour >= 12 && $hour <= 17) {
        return "Добрий день";
    } elseif ($hour >= 18 && $hour <= 23) {
        return "Добрий вечір";
    } else {
        return "Доброї ночі";
    }
}
```

Виклик у розмітці:

```php
<h1><?= getCurrentGreeting() ?>!</h1>
<p><?= formatTitle($taskTitle) ?></p>
```

## Відповіді на контрольні запитання

**1. Принцип DRY (Don't Repeat Yourself)**

DRY означає, що один і той самий шматок логіки не повинен дублюватися в різних місцях коду. Якщо логіку форматування заголовка чи визначення привітання довелося б писати щоразу окремо в кожному місці, де вона потрібна, — будь-яка зміна вимагала б правок одразу в кількох місцях, що збільшує ризик помилок. Винісши цю логіку у функції `formatTitle()` та `getCurrentGreeting()`, ми описуємо правило один раз, а викликаємо його скільки завгодно разів.

**2. Аргументи функції та параметри за замовчуванням**

Аргументи — це значення, які передаються у функцію під час її виклику. Параметри за замовчуванням — це значення, які підставляються автоматично, якщо відповідний аргумент не був переданий явно. У прикладі:

```php
function formatTitle($text, $maxLength = 20) { ... }
```

`$text` — обов'язковий аргумент, `$maxLength` — параметр за замовчуванням: якщо викликати `formatTitle($taskTitle)` без другого аргументу, буде використано значення 20.

**3. Якщо не написати `return`**

Якщо у функції відсутній оператор `return`, вона неявно повертає `NULL`. Тобто після виконання `$x = myFunc();` змінна `$x` міститиме значення `NULL`, навіть якщо всередині функції щось виводилося через `echo`.

**4. Область видимості (scope) змінної**

Область видимості визначає, з якої частини коду змінна є доступною. У PHP кожна функція має власну локальну область видимості: змінні, оголошені зовні (наприклад, `$taskTitle`), за замовчуванням недоступні всередині функції. Щоб звернутися до зовнішньої змінної без передачі її як аргументу, потрібно явно оголосити `global $taskTitle;` всередині функції. Без цього ключового слова доступу до `$taskTitle` немає.

**5. Функція `substr()`**

`substr()` повертає підрядок вихідного рядка. Умовно приймає аргументи:

```php
substr($string, $start, $length)
```

- `$string` — вихідний рядок;
- `$start` — позиція (індекс), з якої починається вирізання (з 0);
- `$length` — необов'язковий аргумент, кількість символів, які потрібно вирізати; якщо не вказано — вирізає до кінця рядка.
